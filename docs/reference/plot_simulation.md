# Plot simulation results

Plot simulation results

## Usage

``` r
plot_simulation(df, x, y, colour = "method", facet = NULL)
```

## Arguments

- df:

  A data frame.

- x:

  Column mapped to the horizontal axis.

- y:

  Column mapped to the vertical axis.

- colour:

  Column mapped to colour.

- facet:

  Optional faceting variable.

## Value

A ggplot object.
