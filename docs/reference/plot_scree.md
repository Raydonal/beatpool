# Plot a scree or cumulative variance curve

Plot a scree or cumulative variance curve

## Usage

``` r
plot_scree(values, cumulative = TRUE, labels = NULL)
```

## Arguments

- values:

  A numeric vector or a list of numeric vectors.

- cumulative:

  Plot cumulative proportions.

- labels:

  Optional names for the list entries.

## Value

A ggplot object.
