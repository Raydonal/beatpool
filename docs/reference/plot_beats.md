# Plot a sample of heartbeats

Plot a sample of heartbeats

## Usage

``` r
plot_beats(X, n = 100L, colour = NULL, alpha = 0.25)
```

## Arguments

- X:

  A beat matrix.

- n:

  Maximum number of beats to draw.

- colour:

  Optional vector of labels used to colour the beats.

- alpha:

  Line transparency.

## Value

A ggplot object.
